# 픽셀 게임

기존 game-devel-main 프로젝트와 독립적으로 실행되는 현재 테스트 게임입니다.

## 실행

폴더 안의 index.html을 Chrome 또는 Edge에서 여세요. 설치나 서버 실행은 필요하지 않습니다.
assets 폴더는 index.html과 함께 보관해 주세요.

## 조작

- WASD 또는 방향키: 이동
- Shift + 이동: 달리기
- 위치 초기화: 시작 위치로 돌아가기

## 포함된 기능

- 궁수 캐릭터의 대기·걷기·달리기 포즈
- 화면 전체를 채우는 석판 바닥과 반복되는 월드
- 화면 가장자리에서 캐릭터를 따라가는 카메라
- 바닥 방향에 맞춘 대각선 성벽, 충돌과 벽 뒤 가림

## 파일

- index.html: 게임 코드와 내장 캐릭터 이미지
- assets/background-floor.png: 바닥 이미지
- assets/maincharacter.png: 캐릭터 원본 포즈 시트

이 프로젝트를 계속 수정하려면 압축을 푼 pixel-game 폴더를 새 작업 폴더로 여세요.
