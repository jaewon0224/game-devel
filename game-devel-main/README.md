# 보이지 않는 미로

보이지 않는 벽을 기억하며 먼저 6점을 얻는 2인용 게임입니다. 한 기기에서 번갈아 하거나, 서로 다른 기기에서 방 코드로 접속할 수 있습니다.

## 실행

Node.js 20 이상을 설치한 뒤 프로젝트 폴더에서 실행합니다. 별도 패키지 설치는 필요하지 않습니다.

~~~sh
npm start
~~~

이 컴퓨터에서는 http://localhost:3000 으로 접속합니다.

## 방 만들기

1. 시작 화면에서 **플레이 → 멀티플레이**를 선택하고, 첫 번째 플레이어가 **방 만들기**를 누릅니다.
2. 다른 기기에서도 **같은 서버 주소**로 접속하고, **방 참가하기**에 6자리 코드를 입력합니다.
3. 두 명이 접속하면 방장이 **게임 시작**을 누릅니다.
4. 각자 자신의 차례에 주사위를 굴리고 이동합니다. 강제 이동 이벤트에서는 이동하는 상대가 직접 방향을 고릅니다.

같은 와이파이라면 서버 실행 시 표시되는 **같은 Wi-Fi 접속** 주소(예: http://192.168.0.10:3000)를 다른 기기에서 여세요. 다른 기기의 localhost는 서버 컴퓨터를 가리키지 않습니다. 운영체제 방화벽에서 Node.js의 해당 네트워크 접속이 허용되어 있어야 합니다.

**서로 다른 와이파이·모바일 데이터에서 플레이하려면** 이 Node 서버를 인터넷에서 접근 가능한 호스팅에 배포하고, 두 기기가 배포 주소로 접속해야 합니다. 정적 파일 전용 호스팅만으로는 방 기능이 동작하지 않습니다. 아직 인터넷 서버 배포는 포함되어 있지 않습니다.

## 접속과 게임 관리

- 새로고침하면 같은 탭의 참가 정보로 원래 방에 다시 연결합니다.
- 한 명의 연결이 끊기면 조작을 잠그고 재접속을 기다립니다. 진행 중인 주사위·이벤트 연출은 마무리될 수 있습니다.
- 방장만 게임을 시작하거나 같은 방에서 새 게임을 시작할 수 있습니다.
- 참가자가 방을 나가면 게임이 끝나고 방장은 대기실로 돌아갑니다. 다른 친구가 같은 코드로 참가할 수 있습니다.
- 방장이 나가면 방이 닫힙니다. 접속자가 없는 방은 30분 후 정리합니다.
- 방과 게임은 메모리에 저장되므로 서버를 재시작하면 사라집니다. 단일 서버 프로세스로 실행하세요.

포트는 PORT 환경 변수로 바꿀 수 있습니다. SSE를 사용하므로 배포 프록시에서 응답 버퍼링을 끄고 스트리밍 연결을 지원해야 합니다.

## 한 기기에서 플레이

시작 화면에서 **플레이 → 2인 플레이**를 선택합니다. 이 모드는 index.html을 직접 열어도 작동합니다.

차례가 바뀌면 현재 플레이어의 출발칸이 아래쪽에 오도록 보드가 180도 회전합니다. 회전은 약 0.8초이며, 진행 중에는 입력을 잠급니다. 방향 버튼과 키보드 방향키는 화면에 보이는 방향으로 이동하고, 말과 칸의 표시는 회전 후에도 똑바로 보입니다. 운영체제의 동작 줄이기가 켜져 있으면 회전 연출을 생략합니다.

## 봇하고 대결

시작 화면에서 **봇하고 대결**을 누르고 **쉬움 / 중간 / 어려움**을 선택합니다. 기존 2인 게임에서 플레이어 2를 봇이 맡습니다. 먼저 6점을 얻으면 승리하며 주사위, 이동 제한, 룰렛 규칙은 같습니다. 인터넷 연결이나 방 생성 없이도 플레이할 수 있습니다.

- **쉬움**: 자신의 차례가 올 때마다 기억한 경로 각각을 38% 확률로 잊고 이동 실수도 자주 합니다.
- **중간**: 경로를 3.5% 확률로 잊으며, 대체로 목적지를 향하지만 가끔 실수합니다.
- **어려움**: 관찰한 벽을 잊지 않고, 가까운 이벤트 칸과 벽 설치·제거를 경로 계획에 활용합니다.

봇은 숨겨진 벽 전체를 읽지 않습니다. 두 플레이어의 실제 이동·충돌과 공개된 벽 변경 결과로 배웁니다. 임시 벽은 다음 라운드에 원래대로 기억하며, 미로 재생성 시에는 배치가 바뀌므로 이전 기억을 초기화합니다. 난이도는 기억과 선택 방식의 차이이며 사람 실력을 수치로 측정한 등급은 아닙니다.

봇이 주사위, 이동, 룰렛과 벽 선택을 자동 처리합니다. 강제 이동의 대상이 사람이면 사람이 직접 방향을 고릅니다. 봇 대결에서는 보드가 계속 사람 쪽을 향합니다. **새 게임**은 같은 난이도로 다시 시작하고, **시작 화면**으로 돌아가 다른 난이도를 고를 수 있습니다. 튜토리얼 버튼은 아직 비활성 상태입니다.

## 검증

~~~sh
npm test
~~~

온라인 게임은 서버가 주사위, 벽, 득점과 차례를 계산합니다. 클라이언트에는 숨겨진 벽 전체를 전송하지 않습니다. 기존 index.html의 한 기기용 게임 규칙을 온라인 게임에도 적용했습니다.
